# intern-day-2-frontend

实习生第二天练习的前端仓库：**React + TypeScript + Vite**，配合后端完成登录与待办清单。

- 后端仓库（配套）：`https://github.com/<你的GitHub用户名>/intern-day-2-backend`
- 页面地址：<http://localhost:5173>

## 页面与功能范围（初稿）

| 页面 | 内容 |
| --- | --- |
| `/login` | 账号、密码、登录按钮、错误提示 |
| `/todos` | 显示当前用户；待办新增、勾选完成、删除 |

必做流程：登录页 → 后端校验 → 功能页 → 读取并显示当前用户 → 使用待办功能 → 退出登录。

## 验收条件

1. 未登录访问 `/todos` 会被重定向回 `/login`。
2. 账号或密码错误时显示后端返回的统一提示。
3. 功能页显示后端返回的用户信息。
4. 待办的增删改都通过真实接口完成，不使用前端 Mock。
5. 接口返回 `401` 时清理本地登录状态并提示重新登录。
6. 刷新页面后的行为与 README 一致，且不只靠前端标志认定已登录。

登录状态处理方式、启动步骤与自测记录在功能完成后补充。
